# RP2040 Developer Board

_**Featuring:**_
 
**MCU: Dual-core Arm Cortex-M0+ @ 133MHz.**

**Storage: 16MB (128Mbit) SPI Flash**

**Power: 3.3V LDO (MCP1700), up to 250mA.**

**Interface: USB-C 2.0 for programming and power.**

**Button for easy flashing.**

**This build features 0402 and QFLN parts so you will need some experience, steady hands, stencil and a solder paste/flux.**



**HOW TO FLASH:**
- This board supports the standard RP2040 bootloader
- Connect the board to your PC via USB-C
- Hold down the BOOTSEL button.
- The board will appear as a mass storage device
- Drag and drop your .uf2 file
